# Ideal Reactor Design

## Overview

Ideal reactors are the foundation of chemical reaction engineering.

In this module, we introduce the fundamental reactor models used for designing chemical and biochemical processes:

- Batch reactor
- Continuous stirred tank reactor (CSTR)
- Plug flow reactor (PFR)
- Packed bed reactor (PBR)

The objective of this module is not only to calculate reactor size, but also to build a computational understanding of reactor design.

## Learning Objectives

After completing this module, students will be able to:

- Understand the physical assumptions of ideal reactors
- Derive reactor design equations from mole balances
- Simulate reactor performance using Python
- Analyze the influence of kinetic parameters and operating conditions
- Calculate reactor volume or catalyst weight requirements
- Compare different reactor configurations for engineering applications
